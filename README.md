# Portfolio Website - Mayuresh Parab

A modern, high-performance developer portfolio built with **React.js**, styled using **Bootstrap 5 & Custom CSS3**, featuring a warm cream aesthetic, fixed transparent glassmorphism navigation, interactive project screenshot queues, and smooth navigation.

---

## 🛠️ Technology Stack
- **Framework**: React.js (v18.3)
- **Styling**: Bootstrap 5 (v5.3.3) & Custom CSS3 (Cream & Earth Palette)
- **Icons**: Bootstrap Icons (v1.11.3)
- **Typography**: Google Fonts (Plus Jakarta Sans)
- **Bundler**: Vite (v5.4)
- **GitHub**: [mayu10-cyber](https://github.com/mayu10-cyber)
